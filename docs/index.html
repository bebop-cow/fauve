The agent that answers only to you.

Fauve is an open-source, privacy-first AI agent, now in early alpha. It is built to read your email as untrusted data and to only search and draft: it never sends, pays or stores passwords.

01 · UNTRUSTED BY DEFAULT

Emails are data, not orders.

Hidden text, tracking images and look-alike instructions are stripped and labeled before a model reads anything. Warnings come from Fauve, never from the model.

02 · ON YOUR DEVICE

Built to keep your data local.

The alpha is designed to run in your browser with a small open model, so there is nothing to upload. A cloud model, if one is ever added, will be opt-in.

03 · OPEN SOURCE

Read every line of code.

On GitHub with a public threat model that lists what is covered and what is not. No analytics, and this page loads nothing from third parties.

Warnings come from Fauve, not the model.
