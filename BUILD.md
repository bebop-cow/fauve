# Building Fauve Houdini (browser extension)

The extension in `extension/` is plain, hand-written JavaScript, HTML and JSON. Nothing in it is minified, bundled or transpiled. The one generated file is `extension/classifier.json`: the weights of the field classifier, built from fake data by two Python scripts in `tools/`.

## Requirements

- macOS, Linux or Windows
- Python 3.12
- Node.js 20 or later (only for `web-ext`)
- The packages pinned in `requirements-dev.txt` (scikit-learn, Playwright)

## 1. Set up

```
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-dev.txt
playwright install chromium
```

## 2. Rebuild the classifier

```
python3 tools/make_hints.py
python3 tools/train_classifier.py
```

- `make_hints.py` writes `tools/hints.csv`: about 2,800 fake form-field hints, each labeled first, middle, last, email, phone or none. It uses a fixed random seed, so it writes the same rows every time. No real personal data is used.
- `train_classifier.py` reads `hints.csv`, trains a logistic-regression classifier on character n-grams (2 to 4 letters), prints its test results, and writes `extension/classifier.json`. The JSON holds the class names, the 0.9 confidence threshold, one bias per class, and one weight per class for each n-gram.

The last line printed should be:

```
wrote classifier.json: 1444 grams, 76 KB
```

With the same Python and scikit-learn versions, the output is the same. Other versions can change the weights in the last decimal places.

## 3. Run the tests

```
bash run_tests.sh
```

All tests must pass. T16–T19 cover the extension and run on local fake pages in headless Chromium. T19 checks that the JavaScript classifier (`extension/classify.js`) gives the same answers as the Python code on every training hint.

## 4. Lint and package

```
npx web-ext lint --source-dir extension
npx web-ext build --source-dir extension --overwrite-dest
```

The zip is written to `web-ext-artifacts/`. The same `extension/` folder is used for Firefox and Chrome; `manifest.json` carries the Firefox-specific settings under `browser_specific_settings`.

## 5. Check the result

1. Serve the fake test page: `python3 -m http.server 8000 --directory tests/fixtures`
2. Load `extension/` unpacked (Chrome/Brave: `chrome://extensions`, Firefox: `about:debugging`).
3. Open `http://localhost:8000/opt-out.html`, enter fake details, and click Fill twice.
4. Expect "Filled 2 field(s)": Forename and Mobile no. filled; Company name, the instruction-like label, the off-screen field and the locked field left empty.

## What is not in the extension

- `ext-src/` and `bench/`: an earlier experiment with local LLMs (WebLLM). Not shipped.
- `tools/hints.csv`: generated by step 2, not committed.
- `web/`: the Fauve and Houdini web pages, separate from the extension.
